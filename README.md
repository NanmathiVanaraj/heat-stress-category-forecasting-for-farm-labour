# heat-stress-category-forecasting-for-farm-labour
Developed a forecasting and classification system to assess heat-stress levels among farm labourers across 19 districts of Tamil Nadu using NASA POWER data covering 2010–2025.
Performed preprocessing and feature engineering using environmental variables and indicators including Heat Index and WBGT (Wet-Bulb Globe Temperature).
Evaluated statistical, machine-learning and deep-learning approaches for temporal and spatial heat-stress analysis.
Implemented and compared ANN, RNN, LSTM and Bi-LSTM models; the project identifies Bi-LSTM as the best-performing approach among the evaluated models.
